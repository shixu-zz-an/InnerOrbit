# IA Redesign

## 当前信息架构
原主 Tab 为 Today、Blueprint、Ask、Love、Me。Love 作为主入口会稀释核心产品定位，也暴露当前关系表单地点有限的问题。

## 新信息架构
主 Tab 收敛为：
1. Today：每日核心闭环和留存入口
2. Blueprint：个人长期资产
3. Ask：AI Guide
4. Me：账户、权益、Journal、Beta 功能和隐私

## 新导航结构
- Today 首页承载每日价值、主行动和最近记录。
- Blueprint 承载完整/预览蓝图和解锁点。
- Ask 承载 AI 问答。
- Me 承载高级版说明、Journal、Relationship Beta、数据和法律。

## 首页应该承担什么任务
让用户知道今天最该关注什么，并推动“追问或反思保存”。

## Tab 应该保留哪些
Today、Blueprint、Ask、Me。

## 哪些页面应该合并
出生日期、出生时间、出生地点、传统计算细节和目标选择合并为一个 Profile Setup 页面。

## 哪些页面应该隐藏或后置
Relationship 从主 Tab 后置到 Me / Labs。

## 核心用户路径
Welcome -> Disclaimer -> Profile Setup -> Preview -> Today -> Ask / Save Reflection。

## 付费转化路径
Preview 锁定完整蓝图、Blueprint 锁定章节、Ask 免费额度触发、Me 高级版说明。
