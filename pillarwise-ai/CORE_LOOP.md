# Core Loop

## 原核心流程
Welcome -> Disclaimer -> Birth Date -> Birth Time -> Birth Place -> Traditional Detail -> Goal -> Generate -> Preview -> Today。

## 新核心流程
Welcome -> Disclaimer -> Profile Setup -> Generate -> Preview -> Today。

## 减少的步骤
把五个资料采集步骤合并为一个可滚动资料设置页，减少连续跳转带来的流失。

## 优化页面
- Welcome 保持价值表达。
- Disclaimer 保留合规确认。
- Profile Setup 合并必要输入。
- Today 新增主行动卡。
- Me 新增 Journal 和 Relationship Beta 的清晰入口。

## 新增反馈
- 生成蓝图、AI 提问、保存反思、升级触发均加入 analytics 事件。
- 首页展示最近 Journal，给用户继续使用的理由。

## 完成核心动作后的下一步
用户生成蓝图后进入 Today；用户查看今日重点后可直接让 AI 拆解；保存反思后回到 Journal。

## 付费转化机会
完整蓝图、更多 AI 追问和关系深度报告。当前前端只做合规说明，真实收费必须接入 Apple IAP。

## 是否影响业务逻辑
不改接口模型，不改后端核心流程；主要改前端路径、入口优先级和状态反馈。
